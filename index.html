Methodology: GitHub's Traffic API only exposes a rolling 14-day window for views and clones. A scheduled collector merges each day's numbers into a permanent local store keyed by date, so history compounds over time instead of resetting every 14 days — the longer this runs, the further back the charts above will reach. Referrers and popular paths reflect GitHub's latest 14-day snapshot only (not accumulated). Stars/forks/watchers are point-in-time snapshots taken on each collection run.
